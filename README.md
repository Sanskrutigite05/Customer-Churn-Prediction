
# 📊 Customer Churn Prediction

## 🔍 Overview

This project predicts whether a customer will **leave (churn)** or **stay** using Machine Learning based on customer behavior and spending patterns.

## 🧠 Models Used

* 🌲 Random Forest Classifier
* 📈 Ridge Classifier

## 📁 Features

* Age
* Tenure Months
* Monthly Spend
* Has Complaints
* Support Calls
* Churn (0 = Stay, 1 = Leave)

## ⚙️ Workflow

1. Data Generation
2. Data Preprocessing
3. Train-Test Split
4. Feature Scaling
5. Model Training
6. Model Evaluation
7. Data Visualization

## 📈 Results

* 🌲 Random Forest Accuracy: **100%**
* 📈 Ridge Classifier Accuracy: **83%**

## 📊 Visualizations

* Churn Distribution Chart
* Feature Importance Graph
* Confusion Matrix
* Boxplots

## 🛠️ Tools Used

Python • Pandas • NumPy • Scikit-learn • Matplotlib • Seaborn • Jupyter Notebook • GitHub

## 🎯 Conclusion

Customers with **high monthly spend, more complaints, and low tenure** are more likely to churn.
Random Forest performed best for churn prediction.
